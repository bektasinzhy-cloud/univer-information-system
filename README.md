
# KazNU Univer ақпараттық жүйесі

## Жоба туралы

Бұл жоба KazNU Univer студенттік ақпараттық жүйесін модельдеуге арналған.

Жүйе студенттерге оқу процесіне байланысты ақпаратты алуға және электрондық қызметтерге өтінім беруге мүмкіндік береді.

## Жобаның мақсаты

Жобаның негізгі мақсаты – студенттер мен университет қызметкерлерінің өзара әрекетін жеңілдететін ақпараттық жүйенің құрылымын модельдеу.

## Негізгі функциялар

Жүйеде келесі негізгі функциялар қарастырылған:

1. Студентті тіркеу және жеке ақпаратын басқару.
2. Оқу пәндеріне тіркелу.
3. Сабақ кестесін қарау.
4. Бағаларды және транскриптті қарау.
5. Оқу-әдістемелік материалдарды қарау.
6. Оқытушы туралы ақпаратты қарау.
7. Электрондық қызметтерге өтінім беру.
8. Өтінімдердің мәртебесін бақылау.

## E-қызметтер

Студент келесі электрондық қызметтерге өтінім бере алады:

* Оқу туралы анықтама;
* Транскрипт алу;
* Жатақханаға сұраным;
* Академиялық демалысқа өтініш.
