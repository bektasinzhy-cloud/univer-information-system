# Жүйеге қойылатын талаптар

## 1. Функционалдық талаптар

### FR-01

Жүйе студентті тіркеу мүмкіндігін қамтамасыз етуі тиіс.

### FR-02

Жүйе студенттің жеке ақпаратын өзгертуге мүмкіндік беруі тиіс.

### FR-03

Жүйе студентке оқу пәндеріне тіркелу мүмкіндігін беруі тиіс.

### FR-04

Жүйе студентке сабақ кестесін көрсетуі тиіс.

### FR-05

Жүйе студенттің бағаларын көруге мүмкіндік беруі тиіс.

### FR-06

Жүйе студентке транскрипт ақпаратын көрсетуі тиіс.

### FR-07

Жүйе электрондық қызметтер тізімін көрсетуі тиіс.

### FR-08

Жүйе студенттен электрондық өтінім қабылдауы тиіс.

### FR-09

Жүйе өтінімнің мәліметтерін тексеруі тиіс.

### FR-10

Жүйе өтінімге бірегей нөмір беруі тиіс.

### FR-11

Жүйе өтінімді деректер базасында сақтауы тиіс.

### FR-12

Жүйе өтінімнің мәртебесін көрсетуі тиіс.

## 2. Функционалдық емес талаптар

### NFR-01

Жүйе пайдаланушы үшін түсінікті интерфейске ие болуы тиіс.

### NFR-02

Жүйе пайдаланушы деректерінің қауіпсіздігін қамтамасыз етуі тиіс.

### NFR-03

Жүйе сұраныстарға қысқа уақытта жауап беруі тиіс.

### NFR-04

Жүйе тәулік бойы қолжетімді болуы тиіс.

### NFR-05

Жүйе деректердің дұрыстығын қамтамасыз етуі тиіс.

## 3. Негізгі пайдаланушылар

* Студент
* Оқытушы
* Университет қызметкері
* Әкімші

## 4. Негізгі процесс

Жобада негізгі процесс ретінде «E-қызметтерге өтінім беру» процесі таңдалды.

Процесс:

1. Студент жүйеге кіреді.
2. E-қызметтер бөліміне өтеді.
3. Қажетті қызметті таңдайды.
4. Өтінім формасын толтырады.
5. Қажетті құжаттарды тіркейді.
6. Өтінімді жібереді.
7. Жүйе енгізілген ақпаратты тексереді.
8. Өтінім деректер базасына сақталады.
9. Студентке өтінім нөмірі беріледі.
10. Студент өтінім мәртебесін бақылай алады.
### FR-13
Жүйе студентке өтінім тарихын көруге мүмкіндік беруі тиіс.
