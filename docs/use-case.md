# Use Case сипаттамасы

## Жүйе

KazNU Univer студенттік ақпараттық жүйесі.

## Actors

### 1. Студент

Студент жүйеге кіріп, өзінің оқу ақпаратымен жұмыс істейді және электрондық қызметтерге өтінім береді.

### 2. Оқытушы

Оқытушы студенттердің оқу нәтижелерімен және оқу процесімен жұмыс істейді.

### 3. Университет қызметкері

Қызметкер студенттердің электрондық өтінімдерін қабылдайды және өңдейді.

### 4. Әкімші

Әкімші жүйені басқарады және пайдаланушылардың құқықтарын бақылайды.

## Негізгі Use Case-тер

### UC-01 – Жүйеге кіру

**Actor:** Студент

**Негізгі сценарий:**

1. Студент жүйеге кіру бетін ашады.
2. Логин енгізеді.
3. Құпиясөз енгізеді.
4. Жүйе мәліметтерді тексереді.
5. Жүйе студенттің жеке кабинетін ашады.

### UC-02 – Сабақ кестесін қарау

**Actor:** Студент

**Негізгі сценарий:**

1. Студент жүйеге кіреді.
2. «Сабақ кестесі» бөлімін таңдайды.
3. Жүйе студенттің оқу тобын анықтайды.
4. Жүйе сабақ кестесін көрсетеді.

### UC-03 – E-қызметке өтінім беру

**Actor:** Студент

**Негізгі сценарий:**

1. Студент жүйеге кіреді.
2. E-қызметтер бөліміне өтеді.
3. Қажетті қызметті таңдайды.
4. Өтінім формасын толтырады.
5. Қажетті файлдарды тіркейді.
6. «Жіберу» батырмасын басады.
7. Жүйе мәліметтердің дұрыстығын тексереді.
8. Өтінім деректер базасына сақталады.
9. Жүйе бірегей өтінім нөмірін береді.
10. Өтінім мәртебесі көрсетіледі.

### UC-04 – Өтінім мәртебесін тексеру

**Actor:** Студент

**Негізгі сценарий:**

1. Студент E-қызметтер бөліміне кіреді.
2. «Менің өтінімдерім» бөлімін ашады.
3. Қажетті өтінімді таңдайды.
4. Жүйе өтінімнің ағымдағы мәртебесін көрсетеді.

## Нәтиже

Use Case моделі студенттің ақпараттық жүйемен негізгі өзара әрекетін көрсетеді.
